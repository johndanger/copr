╔══════════════════════════════════════════════════════════════════════════════╗
║                           TRIGGER POINTS                                     ║
╚══════════════════════════════════════════════════════════════════════════════╝

Automatic Triggers:
  ✅ Push to main branch with *.spec file changes
  ✅ Renovate PR merged
  ✅ Manual spec file edit committed

Manual Triggers:
  🔘 GitHub Actions UI: "Run workflow"
  🔘 GitHub CLI: gh workflow run
  🔘 Manual Copr submission (bypass GitHub Actions)

Does NOT Trigger:
  ❌ Pull request creation (detection only)
  ❌ Non-spec file changes
  ❌ Changes to other branches
  ❌ Draft PRs


╔══════════════════════════════════════════════════════════════════════════════╗
║                           ERROR HANDLING                                     ║
╚══════════════════════════════════════════════════════════════════════════════╝

Error Point                  Action Taken
────────────────────────────────────────────────────────────
❌ Copr package not found    → Job fails, check package config
❌ Rebuild trigger fails     → Job fails, check credentials
❌ Copr SCM clone fails      → Build fails in Copr
❌ Copr SRPM build fails     → Build fails, check spec/sources
❌ Copr package build fails  → Email from Copr (if configured)
❌ Multiple packages         → Builds continue independently
